## - من أنا؟

أنا wailem، مطور ومعلّم مستقل أدمج بين التعليم، الذكاء الاصطناعي، والتقنية لبناء أنظمة ذكية، سريعة، وقابلة للتوسع. أعمل على مشاريع تعليمية، تداول، أتمتة المحتوى، وتحرير الفيديو، مستخدمًا أدوات مفتوحة المصدر وقوة الذكاء الاصطناعي لتحقيق نتائج عالية بأقل موارد.

## - المهارات الأساسية

- البرمجة: Python, Dart, MQL5, JavaScript

## - أبرز المشاريع المنجزة

### 1. مشاريع Python

- بوت تداول Web3 على Testnet (شراء تلقائي + احتساب Gas)
- سكربت ربط نتائج الباكتيست مع GPT/Claude لتحسين خوارزمية التداول
- تحليل شموع (Hammer, Hanging Man) + MFI + SMA باستخدام MT5
- واجهة آلية لتحويل استراتيجيات تداول إلى MQL5 باستخدام Python
- توليد جداول وتقارير تعليمية باستخدام GPT + Google Sheets
- بوت بايثون لتعدين عملة خفيفة باستخدام i7 gen7 لعدة ساعات يوميًا

### 2. مشاريع تداول (MetaTrader 5)

- تطوير Expert Advisor HFT عالي التردد على الذهب (XAUUSD M1)
- سكالبينغ باستخدام MACD, EMA, SMA على جميع الأزواج
- بوت تداول باستخدام مستويات فيبوناتشي والقنوات السعرية
- بوت تداول عدواني بصفقة كل دقيقة حتى في نقص الشروط

### 3. تطبيقات Flutter

- نظام متابعة أداء طلاب متكامل بواجهة Flutter وقاعدة بيانات Firebase
- تطبيق عرض وتحليل بيانات مالية وتعليمية باستخدام Flutter + Python backend
- ربط مباشر بين تطبيق الهاتف وذكاء اصطناعي عبر API

### 4. تحرير المحتوى والفيديو (CapCut)

- نظام آلي لتحرير فيديوهات قصيرة تعليمية ونشرها تلقائيًا على TikTok
- استخدام CapCut scripts + Whisper + ElevenLabs لتحويل النص إلى صوت وفيديو
